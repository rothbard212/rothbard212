# Olá, sou o Jefferson 👋

Estudante de Ciência da Computação na UERJ, construindo um portfólio que atravessa dados/ML e desenvolvimento backend — de pipelines de análise de dados a sistemas automatizados de ponta a ponta.

---

## 🚀 Projetos em destaque

### 🔎 [Mini Motor de Busca Semântico](https://github.com/rothbard212/Mini-Motor-de-Busca-Semantico)
Desafio técnico para vaga de estágio em ciência de dados (FGV IBRE) — um motor de busca semântico aplicado a notícias econômicas. Demonstra limpeza de dados textuais, aplicação de modelos de linguagem e raciocínio sobre similaridade semântica.

**Stack:** Python, NLP, modelos de linguagem

---

### 🛒 [E-commerce Analysis](https://github.com/rothbard212/ecommerce_analysis)
Pipeline completo de análise de dados de e-commerce, cobrindo desde carregamento e limpeza de dados até modelos de Machine Learning e relatórios automatizados.

- Carregamento e tratamento de datasets
- Limpeza e transformação de dados
- Classificação de entregas e pedidos
- Análise de sentimento de reviews
- Treinamento de modelos de Machine Learning
- Detecção de anomalias
- Geração de relatórios automatizados

**Stack:** Python, Pandas, Scikit-learn

---

### 📉 [Rastreador de Preços](https://github.com/rothbard212/rastreador-de-precos)
Sistema automatizado que monitora preços de produtos diariamente, mantém histórico completo em SQLite e envia alertas por email quando detecta queda relevante. Agendado via Windows Task Scheduler, com toda a arquitetura documentada (regras de negócio, casos de borda, decisões de design).

**Stack:** Python · BeautifulSoup4 · SQLite · smtplib · pytest
